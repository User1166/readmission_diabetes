# Diabetes 30-Day Readmission Risk Portal

Veritas AI International High School Hackathon 2026 · AI + Health track

A prototype that estimates how likely a diabetic patient is to be readmitted to hospital within 30 days of discharge. It is designed for discharge coordinators deciding which patients need intensive follow-up calls. It includes a calibrated probability, a threshold slider that shows the trade-off between missed readmissions and false alarms, and a fairness audit by race, gender and age.

**This project is a prototype and is not medical advice.**

## Results (held-out test set, 20,075 encounters, evaluated once)

| | Raw model @ 0.30 | Calibrated model @ 0.12 (chosen) |
|---|---|---|
| ROC-AUC | 0.667 | 0.667 |
| PR-AUC (random guessing: 0.115) | 0.231 | 0.216 |
| Recall (readmissions caught) | 59.5% | 56.8% |
| Precision (flagged patients readmitted) | 18.1% | 18.5% |
| Patients flagged | 37.7% | 35.2% |
| Accuracy | 64.5% | 66.4% |

Calibration (isotonic, fitted on validation data):
- Average predicted risk: 0.114 (observed rate 0.115). Before calibration it was 0.286.
- Brier score: 0.097 calibrated, 0.127 raw, 0.102 for always predicting the base rate (lower is better).

Accuracy is lower than the naive "always LOW" baseline (88.5%), which never flags anyone. Recall, precision and PR-AUC are the measures to use for this rare outcome.

## Fairness audit (calibrated, threshold 0.12)

- Recall gap by race: 0.241. The "Other" group has 313 patients and 30 readmissions, so this estimate is very uncertain.
- Recall gap by gender: 0.062.
- Recall gap by age: 0.122. Patients aged 70+ are flagged more often (43.6%) than those under 50 (26.0%), partly because older patients are readmitted more often.

Race and gender are not model inputs. They are used only in the audit.

## Method

- **Data:** Diabetes 130-US Hospitals for years 1999–2008 (UCI Machine Learning Repository). 101,766 encounters from 70,439 patients. Encounters where the patient died or went to hospice (discharge IDs 11, 19, 20, 21) were removed because those patients cannot be readmitted, leaving 100,114 encounters. Outcome: readmitted within 30 days (11.3%).
- **Split:** 60% train, 20% validation, 20% test, split by patient so no patient appears in more than one set.
- **Features:** 46 model features (11 numeric, 35 categorical). Missing values are filled with the median (numeric) or labelled "Missing" (categorical). Diagnosis codes are grouped into standard ICD-9 chapters. Weight is excluded (97% missing).
- **Model:** Soft-voting ensemble of a random forest (balanced class weights) and a histogram gradient-boosting model. Hyperparameters were chosen by randomised search (15 candidates, 3-fold cross-validation on training data only). Best cross-validated ROC-AUC: 0.6725.
- **Calibration:** Isotonic regression fitted on validation data. Raw probabilities were about 2.5 times higher than observed rates; calibration corrected this.
- **Threshold:** 0.12, chosen on calibrated validation probabilities using Youden's J statistic.
- **Reuse of the test set:** The test set was used once for the main results and again to check calibration. Both sets of numbers are reported.

## How to run

1. Open Google Colab and create a new notebook. Use a **CPU** runtime (no GPU is needed).
2. Paste the full training script into one cell and run it. It will:
   - mount Google Drive,
   - download the dataset from UCI if it is not already present,
   - load the saved model from Drive, or train it once if no saved model exists,
   - calibrate the model and print the results,
   - launch the calibrated Gradio app and print its link.
3. Open the link the cell prints. Enter patient values, press **Evaluate Readmission Risk**, and use the threshold slider to see the trade-off.

**Training time:** The first run that trains the model takes about 10–20 minutes on Colab's CPU. Later runs that load the saved model take about a minute.

**Retraining:** Set `RETRAIN=1` as an environment variable, or delete the saved model file from Drive, to train again from scratch.

**Reproducibility:** The script prints a fingerprint after evaluation (test ROC-AUC, PR-AUC and the sum of predicted probabilities). The values printed in two sessions that loaded the same saved model were identical: ROC-AUC 0.667187, PR-AUC 0.230816, sum 5745.1740. A full retraining comparison has not yet been run.

## Limitations

- Modest performance: ROC-AUC 0.67. At the chosen threshold, about 4 in 5 flagged patients are not readmitted, and about 43% of readmissions are missed.
- Single probabilities can be wrong. Calibration is correct on average, but an individual estimate may be far from what happens.
- Data is from 1999–2008 and from a single hospital network. Readmissions to other hospitals are not recorded.
- Not validated on current data, other hospitals or other populations.
- The race recall gap rests on very small groups and should be treated as a warning, not a conclusion.
